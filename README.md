# Echo

Echo

Echo is a local, privacy-preserving reflection system built on Phi-3, designed to process and reflect on user-described dreams.

A user shares a dream in their own words, and Echo responds with brief, presence-based reflections. The system does not interpret dreams symbolically, assign meaning, or provide explanations. It avoids advice, reassurance, and emotional dependency, focusing instead on acknowledging the emotional tone and lived experience expressed in the dream.

Voice output is deterministic and user-controlled. Echo uses backend TTS routing and can automatically switch between male and female voices by detecting contextual cues such as “he” or “she” in the reflected text, while still allowing explicit manual voice selection. This prevents inconsistent or unintended voice behavior.

Echo runs entirely locally and does not rely on cloud services, external APIs, or user profiling.

What Echo is not

Not a dream interpretation system

Not a therapist or mental health tool

Not a conversational assistant

Not an emotional companion

Not an advice or recommendation system

Echo is intentionally constrained by design.
